---
name: Phase sequencing
description: The user's rule for work organized into sequential project phases.
---

Do not start a later project phase until the preceding phase is complete. Each phase depends on the prior phase being done.

**Why:** The user explicitly asked that incomplete phases block all subsequent phases.

**How to apply:** Check the preceding phase's agreed scope and completion status before beginning later-phase implementation. Keep later-phase work unstarted while a prerequisite is incomplete.
